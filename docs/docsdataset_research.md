# Dataset Research

## FashionGen Dataset

FashionGen is a large-scale fashion dataset developed for text-to-image generation tasks.

Features:
* High-quality fashion images
* Detailed product descriptions
* Multiple clothing categories
* Useful for generative AI applications

Applications:

* Text-to-image generation
* Fashion captioning
* Style understanding

## DeepFashion Dataset
DeepFashion is one of the most widely used fashion datasets.

Features:
* Clothing categories
* Attribute annotations
* Landmark detection
* Fashion image retrieval

Applications:
* Fashion classification
* Attribute prediction
* Clothing recommendation systems
